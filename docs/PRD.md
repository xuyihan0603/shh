# 首店预订首版

单店员工为客人办理散台、包间、多桌预订与散客登记。按日期、午晚餐核对桌态，确认时一单内全部桌位同时占用。前台及店长处理全店订单，客户经理管理自己的订单，他人订单遮挡手机号。保留换桌、取消和款项调整记录。

财务按用餐日核对单日和整月的员工、单数、桌数、最终消费、订金和待补笔数，散客单列，取消单只进明细。从待补列表可进入订单详情，店长可以录入消费金额。支持微信邀请函、预约短信对接、网页管理与双工作表 Excel 导出。上线时按门店真实桌位、账号和未来预订逐笔交接。

首版验收覆盖并发抢桌、多桌冲突回滚、午晚餐独立、换桌、取消、散客、手机号权限、邀请函、日月汇总和订金不重复计入消费。使用附件中的 2,400 元消费、500 元订金示例核算。

员工账号在首次登录时绑定姓名，新预订记入当前员工账号。用客人手机号匹配历史到店记录，自动填入已有姓名，允许本单修改。多桌按一笔订单计算，取消和待到店的订单不计次。

客群按同一联系电话的累计到店次数分为新客（1 次）、可发展客（2–3 次）、VVIP（4 次及以上）。店长与财务可以查看三类客群的累计人数及最近 4 周或 8 周的每周到店对比。

试点门店为珊瑚海。24 个桌名按门店提供的清单录入。205 为二楼包房；其他数字桌号先按首位分楼层，卡1、阳光房B1 的楼层、其余桌位类型和容量留待门店确认。门店地址与订餐电话按预订消息模板录入，店长可在后台更新。员工选择微信联系人并确认发送预订文字，也可复制正文或交给手机短信应用发送。
