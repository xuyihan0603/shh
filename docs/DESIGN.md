# 使用流程

桌态为启动页。先选用餐日、餐段，再按楼层选桌。预订单列表可查看详情、换桌、取消、登记款项和发邀请。日报从汇总进入员工明细，管理后台用于电脑核对和门店配置。

## 珊瑚海小程序视觉

门店原商标保存在 `miniprogram/assets/coral-logo.jpg`。深海蓝绿（#103947）用于导航与主按钮，珍珠白（#F6F4EE）用于页面底色，香槟金（#BD9354）呼应商标。桌号、原接单人、金额和订单状态采用可读的原生文字。客群用新客、可发展客、VVIP 三档，状态同时提供文字和颜色。

### ImageGen 横幅提示词

首页横幅由内置 ImageGen 生成，项目使用 `miniprogram/assets/steamed-croaker.jpg`。

生成一张 3:1 超宽、窄幅横版的写实中餐美食摄影横幅，作为「珊瑚海」台州小网海鲜餐厅员工订座小程序首页。
左侧约 48% 是干净、低反差的深海青桌面和自然暗部，供程序叠加商标和店名。右侧是镜头焦点：一尾完整清蒸东海小黄鱼，淡金鱼皮，有细姜丝和葱丝，盛在浅青釉长圆瓷盘，少许透亮蒸鱼汁。鱼与盘沿有自然错落的对角线，主体集中在画面中间高度，适应宽幅裁切。侧上方温暖的自然光勾出鱼皮和瓷釉，暗部偏海蓝绿。俯拍略带角度，像江南沿海餐厅的当季菜品杂志内页，克制、真实、安静。全出血，画中没有文字、商标、水印、边框或界面元素。
