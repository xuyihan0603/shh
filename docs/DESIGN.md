# 使用流程

桌态为启动页。先选用餐日、餐段，再按楼层选桌。预订单列表可查看详情、换桌、取消、登记款项和发邀请。日报从汇总进入员工明细，管理后台用于电脑核对和门店配置。

## 珊瑚海小程序视觉

门店原商标保存在 `miniprogram/assets/coral-logo.jpg`。深海蓝绿（#103947）用于导航与主按钮，珍珠白（#F6F4EE）用于页面底色，香槟金（#BD9354）呼应商标。桌号、原接单人、金额和订单状态采用可读的原生文字。客群用新客、可发展客、VVIP 三档，状态同时提供文字和颜色。

### ImageGen 横幅提示词

为珊瑚海台州菜·小网海鲜的微信门店桌态页制作一张超宽横幅底图。以参考商标的金色珊瑚分枝和圆弧海浪为造型语言，延展成深海蓝绿漆面上的香槟金铜版画：右侧近景是一株清晰优雅的金线珊瑚，下方两三道细金潮线通向远处台州海岸。左半幅保持均匀暗海蓝绿留白，供前端叠加商标和店名。宽约 3:1，主要纹样在中间水平带，适合窄幅裁切。克制、细腻，像高级海鲜餐厅的纸质菜单封面。画面不含文字、字母、标志复刻、边框或界面控件。

概念稿位于 `docs/珊瑚海接待台设计稿.png`。实际小程序使用原生日期、餐段、楼层与桌型筛选控件；门店名称、桌位与订单数据由小程序实时填充。
